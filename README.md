# Introduction to Git and GitHub — Course Notes

Welcome to this collection of notes and learning materials for the **Introduction to Git and GitHub** course. The folders follow the course modules, moving from version-control fundamentals to using Git locally, working with remotes, and collaborating with others.

## 🗂️ Repository Structure

The course materials are organized into four module folders:

| Module | Topic | Folder |
|--------|-------|--------|
| 1 | Introduction to Version Control | [Module_01](./Module_01/) |
| 2 | Using Git Locally | [Module_02](./Module_02/) |
| 3 | Working with Remotes | [Module_03](./Module_03/) |
| 4 | Collaboration | [Module_04](./Module_04/) |

Each module includes course documents such as:

- **`docs/`** — original Word documents, including notes, readings, study guides, glossaries, and Exemplars
- **`previews/`** — PDF versions of the Word documents for viewing directly in GitHub

Some modules also contain additional reference documents. Each module keeps its DOCX files in `docs/` and corresponding PDF previews in `previews/`.

## 💻 Git Command Reference

[`git_commands.txt`](./git_commands.txt) contains the Git commands collected during the course. They are grouped in a learning sequence: configuration and repository setup, local changes and history, undoing changes, branches, and remote collaboration.

Commands using placeholders such as `<branch-name>`, `<file_name>`, or `<URL>` need values appropriate to your repository. Some commands in the reference are alternatives rather than commands to run consecutively. Take care with commands that discard local changes or rewrite shared history, especially `git checkout -- <file>` and `git push -f`.
